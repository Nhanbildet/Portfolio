Analyse de l'investissement Airbnb à Bordeaux

## Contexte
- Un investisseur potentiel envisage d’investir dans des biens Airbnb à Bordeaux.
- Objectif de revenu annuel : environ 30 000 €.
- Recommandation : investissement à rendement attractif (sur la base des données d’une année).

## Objectifs
- Identifier les quartiers les plus rentables à Bordeaux pour l’investissement,
- Déterminer les types de biens susceptibles de générer le rendement attendu,
- Prendre en compte les aspects opérationnels tels que la gestion des propriétés, l’ameublement et le fonctionnement quotidien

## Méthodologie
- Collecte des données Airbnb sur 1 an.
- Analyse des revenus par quartier et type de propriété.
- Évaluation des KPI : prix moyen, taux d’occupation, revenus estimés.

## Données utilisées
- Listings Airbnb à Bordeaux.
- Informations sur les types de biens, nombre de chambres, capacité d’accueil.
- Données sur la gestion et l’ameublement des propriétés.

## Project Phases

* Phase 1 – Identification des KPI
Identifier les indicateurs clés de performance liés à :
- le type de propriété,
- le modèle de location,
- la tarification,
- les revenus potentiels.

* Phase 2 – Analyse détaillée des propriétés
Examiner les facteurs spécifiques à chaque bien :
- Ameublement et équipements,
- Exigences opérationnelles,
- considérations de gestion.

* Phase 3 – Agrégation et prévisions
Combiner les résultats obtenus et générer des projections pour orienter les décisions d’investissement.

# 🏡 Airbnb Investment Analysis – Data Pipeline & Analytics (Microsoft Fabric)

## 📊 Project Overview

This project analyzes the **Airbnb short-term rental market** to identify the most profitable investment opportunities in a highly competitive environment.

The objective is to determine which combinations of **location, property type, price level, and capacity** can generate a target revenue of:

💰 **€3,000 per month (€36,000 per year)**

The analysis focuses on three French markets:

* 📍 **Bordeaux**
* 📍 **Lyon**
* 📍 **Pays Basque**

Using a dataset of **26,000 Airbnb listings**, the project explores host profiles, property characteristics, pricing structures, and occupancy patterns to identify the most attractive investment segments.

---

# 🏗️ Data Architecture

The project implements an **end-to-end data pipeline in Microsoft Fabric** using a **Medallion Architecture (Bronze – Silver – Gold)**.

```
Airbnb Dataset
      ↓
Fabric Lakehouse (Bronze Layer)
      ↓
PySpark / SQL (Silver Layer)
      ↓
Dataflows Gen2 (Data Cleaning)
      ↓
Star Schema Model (Gold Layer)
      ↓
Power BI Dashboards (Analytics)
```

### Pipeline Steps

1️⃣ **Data Source**
Airbnb dataset containing listings, hosts, pricing, and reviews.

2️⃣ **Bronze Layer – Fabric Lakehouse**
Raw data storage and centralized ingestion of source datasets.

3️⃣ **Silver Layer – PySpark / SQL**
Data transformation, filtering, and structuring of relevant variables.

4️⃣ **Silver Layer – Dataflows Gen2**
Data cleaning and preparation for analytical usage.

5️⃣ **Gold Layer – Star Schema Model**
Creation of a business-ready analytical model with **fact and dimension tables**.

6️⃣ **Analytics Layer – Power BI**
Interactive dashboards used to analyze market performance and investment opportunities.

# 📈 Key Analysis

The dashboards explore several dimensions of the Airbnb market:

* 👤 Host profiles and distribution
* 🏠 Property types and accommodation capacity

* 📊 Occupancy rate patterns
* 🧭 Market concentration by location
* 💼 Investment profitability indicators

### Key KPIs

* 💰 Average price
* 📉 Occupancy rate
* 📊 Estimated monthly revenue
* ⭐ Host activity and rating levels

---

# 📊 Dashboard Insights

The analysis highlights several important trends:

* Most listings are managed by **local hosts with small portfolios**
* **Entire homes and private rooms** dominate the supply
* **Medium-capacity properties (2-4 people)** represent the core market segment
* Market maturity creates strong competition, making **location, pricing, and service quality key performance drivers**
